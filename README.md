## 📌 Overview

**CheezyBite** is a **production-ready full-stack pizza ordering platform** designed for performance, scalability, and real-time user experience.

It enables users to:
- Browse pizzas 🍕  
- Customize and order  
- Receive real-time updates  
- Get email notifications  

---

## ✨ Key Highlights

- ⚡ Real-time order tracking (Socket.io)  
- 🔐 Secure authentication (JWT + bcrypt)  
- 📧 Email integration (Resend)  
- 🎨 Modern UI with animations (Framer Motion)  
- 📊 Analytics dashboard (Recharts)  
- 🧠 Lightweight global state (Zustand)  
- 🧪 Fully tested (Jest + RTL)
